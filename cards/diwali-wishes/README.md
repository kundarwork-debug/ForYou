# Diwali Wishes Card

A standalone, responsive digital greeting card for the For You website.

## Files
- `index.html` — card creator and recipient view
- `style.css` — layout and festive card design
- `script.js` — live personalisation, optional photo preview, and share-link generation

## Share behaviour
The share link stores the recipient name, message, and sender name in URL query parameters. Uploaded photos are preview-only and are not included in the share link.

## Local preview
Open `index.html` in a browser, or visit:

`/cards/diwali-wishes/`
